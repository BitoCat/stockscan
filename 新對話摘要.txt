## TradingView 指標快訊（直送 Telegram）✅ 2026-07 現行做法

### 架構
```
TradingView 快訊 Webhook → Telegram Bot API 直接發布到頻道
```
- 台股報報（-1003883576984）、美股報報（-1003990900011）
- 不經任何中繼伺服器，TradingView 快訊設定裡直接填 Telegram API 網址

### 限制與注意事項
- TradingView Premium 的篩選器快訊只能對「兩個清單」掃描發布（伺服器端配額，
  中繼站或 Webhook 都無法突破）。目前台股、美股各用掉名額
- 想擴充標的：優先把清單「加大」（單一清單可容納數百檔）而不是「加多」；
  再不夠的選項：升級 Ultimate，或自建掃描器（參考 daily_scanner.py 模式，
  GitHub Actions/Railway 排程 + Telegram 推播，不受配額限制）
- Bot Token 寫在每條 TradingView 快訊的 URL 裡，若 Token 重置需逐條更新
- 台股訊號只顯示代號、無中文名稱補齊（原補名功能隨 tw-alert-bot 除役）

### 歷史紀錄
- 前代方案 tw-alert-bot（TradingView → Railway FastAPI → 查 tw_stocks 補中文名 → Telegram）
  已於 2026-07 除役，Railway 服務已關閉，GitHub repo（BitoCat/tw-alert-bot）保留封存。
  未來若要恢復「補中文名／訊息加工／分流」需求，可參考該 repo 重建

## 技術架構

### 前端（GitHub Pages）
純靜態 HTML + JS，無框架。

**重要限制：**
- Safari 不支援 AbortSignal.timeout()：所有 fetch 不可加此參數
- supabase-js 在 GitHub Pages 環境 apikey header 帶不進去：新頁面用直接 fetch；舊頁面需在 head 加 CDN：
  ```html
  <script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2.39.3/dist/umd/supabase.js"></script>
  <script src="js/supabase.js"></script>
  ```
- 新頁面（radar.html、news.html、daily.html 強力買入區）使用直接 fetch
- GitHub Pages 有 CSP 限制，內嵌 script 可能被擋 → 付款頁面放在 Railway 上

**Supabase 直接 fetch 標準寫法：**
```javascript
const SUPABASE_URL = 'https://kldumnxdlgovaxtiszyn.supabase.co';
const SUPABASE_ANON = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...';
const SB_HEADERS = {
  'apikey': SUPABASE_ANON,
  'Authorization': 'Bearer ' + SUPABASE_ANON,
};
```

## 概念股雷達（concepts.html）✅ 2026-06-11 完成（台股+美股）

### 架構
concepts.html（🇹🇼/🇺🇸 切換頁籤）
→ data/concepts.json（台股 20 概念約 150 檔）
→ data/us_concepts.json（美股 18 概念約 100 檔）
→ Railway POST /concept-analysis（批次估值，concept_analysis.py Blueprint）

### 概念清單維護（不用動程式）
- 直接編輯 JSON：台股 data/concepts.json、美股 data/us_concepts.json
- 台股 code 只放四碼數字（後端自動試 .TW 再 .TWO）；美股直接放代號（NVDA）
- category 可自由新增，前端自動產生新分組按鈕
- 金融類概念加 "valuation_hint": "pb"（台股金融股、美國銀行股已標）
- 單一概念檔數無硬上限：超過15檔時前端自動分批呼叫後端（每批15檔）再合併，
  25檔約20-40秒（快取後秒回）。建議單一概念控制在25檔內以維持聚焦比較
- JSON 改壞時整片按鈕會消失 → 用 jsonlint.com 驗證（常見錯誤：多/少逗號、全形引號）
- 美股特殊代號：Block=XYZ（原SQ）、SanDisk=SNDK（2025從威騰分拆）

### 後端（trading-bot/concept_analysis.py，Flask Blueprint）
- 註冊：主程式 app = Flask 下方 from concept_analysis import concept_bp + register_blueprint
- POST /concept-analysis：body {stocks:[{code,name}], valuation_hint}，一次最多15檔，
  5線程並行，記憶體快取10分鐘
- GET /concept-analysis/test?code=XXXX：瀏覽器單檔測試（回傳含 "ver" 版本標記）
- _resolve：code 含英文字母 → 美股直接用原代號；純數字 → 台股試 .TW/.TWO
- 四種估值法：analyst（分析師目標價）、pe（近4年歷史PE區間×目前EPS）、
  pb（近4年歷史PB區間×目前每股淨值）、dividend（近5年均股利×16/20/32）
- 股利法過濾：dividend fair < 現價25% 時略過（NVDA 這類低殖利率成長股不適用）
- fair_basis 優先序：hint=pb → 分析師≥3位 → pe/pb 中位數(history) → dividend
- divergence_pct：各方法合理價分歧度，>80% 前端顯示 ⚠️（估值重評中的成長股）

### 前端（concepts.html）
- supabase CDN 做 auth + plan 檢查（free 鎖定），分析資料直接 fetch 後端
- 🇹🇼/🇺🇸 頁籤切換載入對應 JSON；概念按鈕牆依 category 分組
- 表格預設按 upside_pct 排序，欄位可點擊排序；合理價旁標依據（法人/淨值/歷史/股利）+ ⚠️
- 點列展開四種估值法明細卡片；股票代號連到 diagnosis.html?symbol=代號
- 上方阻力/下方支撐 = 近60交易日高低點；含全站共用底部 tabbar（概念股設 active）
- 首頁 index.html quick-btns 已加 🧩 概念股雷達入口

### 開發注意事項（教訓）
- ⚠️ Safari 會快取 GET API 回應：測試 API「結果連小數點都不變」時先懷疑瀏覽器快取，
  網址加 &x=隨機數 或 Cmd+Shift+R 排除。曾因此誤判部署失敗，除錯半天

### 八個型態(毛哥教學邏輯:兩個時期、兩種進場+衍生)
| 型態代號 | 名稱 | 條件摘要 |
|---------|------|---------|
| pullback_ma20 | 🔵強勢回調月線起漲 | 價>SMA10且價<SMA25(月線攻防區,毛哥TV原式)+月線>季線+距高點≤30% |
| deep_pullback | 🔄深度回調起漲 | 同月線攻防區但月線≤季線(深修正後起漲)+距高點≤45% |
| pullback_ma60 | 🔷強勢回調季線起漲 | 價>SMA10+價格在季線±5%+季線上揚+距高點≤35% |
| reversal_ma20 | 🟢低檔站上月線 | 昨日月線下今日站上+低檔(距低點≤25%)+量比≥1.5 |
| reversal_ma60 | 💚低檔站上季線 | 近5日從季線下站上+月線上彎+距低點≤30% |
| high_52w | ⭐突破52週新高 | 收盤創一年新高+量比≥1.2 |
| bull_alignment | 🚀多頭排列 | SMA10>20>60且價在三線上+距高點≤20% |
| laggard | 🏃落後補漲 | 價>月線>季線但距高點20~45%(尚未大漲) |

- 設計原則: 全部用「站上/位置」邏輯,不用交叉(符合毛哥教學語言)
- 型態演進紀錄: 回調型態最初用「回踩不破」邏輯→改「跌破又站回」→最終定案毛哥TV原式
  「SMA10之上SMA25之下」的月線攻防區;衝刺期(月線>季線)與修復期(月線≤季線)拆成兩類
- 型態是每日快照,某型態某天0檔是正常的(前端顯示友善提示)

## 開發注意事項

### 關鍵限制
- Safari 不支援 AbortSignal.timeout()：fetch 不可加此參數
- Safari 會快取 GET API 回應：測試時網址加 &x=隨機數 或 Cmd+Shift+R
- supabase-js apikey header 問題：新頁面用直接 fetch
- 權限判斷禁用 plan !== 'free' 寫法(比特聯盟共用 Supabase,等級值會誤放行),一律用 hasAccess 白名單
- JS 字串內禁止用全形字元
- GitHub Actions 版本要用 v4
- profiles 表沒有 email 欄位（需用 get_profile_by_email RPC）
- Yahoo Finance / EDGAR 需從 Railway 後端抓，不能從 GitHub Actions 直接抓
- GitHub Pages 有 CSP 限制，含內嵌 script 的互動頁面放在 Railway 上

### Supabase RLS
- tw_fund_positions：anon SELECT
- daily_news：anon SELECT + INSERT + DELETE
- scan_watchlist：anon 全部權限
- scan_results：anon SELECT + INSERT + DELETE
- tw_stocks：anon SELECT（service_role 負責寫入）
- memberships：service_all policy（Railway 後端可讀寫）

### Railway 維運
- 方案：Hobby（$5/月）
- 健康檢查：/test
- 不需要加 port，public URL 已是 443
- tg-member-bot 在 honest-vibrancy project
