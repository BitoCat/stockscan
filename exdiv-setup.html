除息接力初次設定

每個帳戶(例如 MEI、品雯)各做一次。資料從你的瀏覽器直接加密送到 GitHub,不經過其他伺服器。
金鑰、憑證、身分證字號只輸入在帳戶本人知情同意的裝置上,不要交給別人代填。 這個頁面的程式碼是公開的,可以檢查它只連線到 GitHub 與 Telegram。

策略規則(回測 2016~2026)

  • 候選:已公告除息、純現金配息的上市個股,股價 ≥ 10 元、均量 ≥ 200 張
  • 門檻:現金股利 ÷ 股價 ≥ 5%,合格名單內挑哪一檔都可以
  • 勾選後下一個交易日 14:00 盤後定價買進;除息前一個交易日一律賣出
  • 建議同時 3~5 檔、每檔金額自己分配

1連結 GitHub

  1. 程式放在私人 repo exdiv-trader(MEI、品雯等帳戶都在同一個 repo,各用自己的金鑰前綴)
  2. 到 建立權杖:Repository access 只選 exdiv-trader; 權限開 Contents、Secrets、Actions 三項,都選 Read and write → Generate → 複製

2帳戶

金鑰前綴會用代號的大寫,例 mei → MEI_API_KEY。

3Telegram 通知

  1. 可以沿用 ETF 輪動用的機器人;要新開就在 Telegram 搜尋 @BotFather → /newbot → 複製 token
  2. 打開機器人 → 按 Start,再隨便傳一句話給它

4永豐 API(要自動下單才需要)

  1. 用帳戶本人登入永豐金證券網站 → 簽署中心 → 簽所有 API 相關條款
  2. API 管理 → 新增 API Key:勾行情、帳務、交易(有「正式環境」也勾),不要設 IP
  3. 同一頁按 下載憑證,得到 Sinopac.pfx
只在瀏覽器裡轉換,加密後直接存進 GitHub Secrets。
同一個人在永豐有兩個證券戶(例如品雯已有 ETF 輪動帳戶),這裡一定要填新帳戶的證券帳號;沒填的話程式為了安全不會下單。 不確定帳號的話先留空,完成後按「正式環境檢查」,Telegram 會列出每個帳號末 4 碼。

5寫入 GitHub

    ✓ 設定完成!約 1 分鐘後 Telegram 會收到「設定已啟用」。
    模式先設為「只通知」:程式只發 Telegram 提醒、不會下單。 之後到 選股頁面 勾選候選、填金額,也在那裡切換模擬或真單。
