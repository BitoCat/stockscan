ETF 輪動・分享者步驟(毛哥用)

分享給一位朋友時照這頁做;朋友那邊看 設定步驟頁。勾選只記在這台裝置,換下一位朋友時按最下面「全部清除」。

0一次性:範本加部署金鑰

只要做一次,所有朋友共用。已經加過就勾完成。
  1. 打開範本 Deploy keys 頁 → Add deploy key
  2. Title:朋友自動更新;Key:貼「範本自動更新金鑰-公鑰.txt」那一行(ssh-ed25519 開頭)
  3. 不要勾 Allow write access → Add key
打開 Deploy keys
私鑰(BEGIN OPENSSH PRIVATE KEY 那段)不要貼在這裡,GitHub 也會拒收。私鑰自己保存好,只私下給朋友。

1開範本權限給朋友

  1. 範本 → Settings → Collaborators → Add people → 輸入朋友的 GitHub 帳號 → 送出邀請
  2. 請朋友到 Email 或 GitHub 通知 按 Accept invitation
打開 Collaborators
這個權限只是讓她能「從範本建立 repo」,建好就收回。

2傳給朋友兩樣東西

  • 設定步驟頁連結:https://bitocat.github.io/stockscan/etf-guide.html
  • 程式自動更新金鑰:「範本自動更新金鑰-私鑰.txt」的全部內容,用 LINE 私訊等方式傳(不要貼在群組)
重新設定的朋友(已有舊 repo)也傳同樣的東西,她照頁面從第 0 步做。

3朋友建好 repo 後收回權限

  1. 朋友說「第 2 步完成」後,範本 → Settings → Collaborators → 她的帳號旁 Remove
打開 Collaborators
收回後她的 repo 照常運作;程式更新改靠部署金鑰,不需要協作者權限。

4確認朋友設定成功

請她截圖這幾則 Telegram 給你:

  • 「設定已啟用」(第 4 步寫入後約 1 分鐘)
  • 「程式更新」或 Actions 的程式自動更新綠勾(第 5 步)
  • 永豐模擬測試、正式環境檢查都成功(第 6 步,平日 08:00–18:00)
只要截圖,不要請她傳金鑰、憑證或身分證字號。

5朋友先跑「只通知」

  • 第一次換股前一天晚上 20:00 她應該收到「明天換股預告」,當天 13:25 收到換股通知
  • 沒收到:多半是 cron-job.org 權杖或網址錯(第 7 步),請她截 cron-job.org 的執行紀錄
  • 確認一兩次換股正常後,她再到設定頁改「模擬」或「真單」

平常維護

程式更新怎麼到朋友那邊

  • 你請 Claude 改程式 → Claude 會同時更新你的 etf-rotation 和範本
  • 朋友的 repo 每週日 09:17 自動從範本更新,有更新時她會收到「程式更新」通知;急的話請她到 Actions → 程式自動更新 → Run workflow
  • 排程檔(.github/workflows/)GitHub 不允許自動更新;有改時她會收到提醒,需要手動複製(或請 Claude 寫步驟)

私鑰外流或想換一組

  1. 範本 → Settings → Deploy keys → 刪除「朋友自動更新」(立刻失效)
  2. 請 Claude 產生新的一組,把新公鑰加回 Deploy keys
  3. 新私鑰私下傳給每位朋友,請她們到自己 repo → Settings → Secrets and variables → Actions → TEMPLATE_KEY → Update,貼上新的
外流的影響只有「範本程式碼被看到」,看不到任何人的設定、金鑰或帳戶。

朋友不用了

  • 她到設定頁按暫停,或直接刪除自己的 repo;你這邊不需要做什麼
  • 如果在意她還能更新程式,換一組部署金鑰(上一張卡片)
