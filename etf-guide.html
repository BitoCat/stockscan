ETF 輪動設定步驟

照順序做完 8 步,每做完一步勾右邊的「完成」(會記在這台裝置)。大約 30 分鐘;第 6 步要平日 08:00–18:00。

0先準備好這些

  • GitHub 帳號,而且分享者已開權限讓你看得到範本(打開 範本 看得到就 OK)
  • Telegram 機器人 Token:Telegram 找 @BotFather → /mybots → 選你的機器人 → API Token (沒有機器人:/newbot 建一個)
  • Telegram 通知 ID:舊版 repo 的 accounts/main.yaml 裡 telegram_chat 那串數字(第一次設定的話,第 4 步的設定頁會教你查)
  • 永豐 API Key、Secret Key:Secret Key 只在建立時顯示一次;沒存下來就到永豐 API 管理頁刪掉舊的、重建一組 (勾 行情、帳務、交易、正式環境,不設 IP)
  • 憑證檔 Sinopac.pfx(在電腦裡)與憑證密碼(預設是身分證字號)
  • 程式自動更新金鑰:分享者私下給你的一段文字(開頭是 -----BEGIN OPENSSH PRIVATE KEY-----)
建議用電腦操作(第 4 步要上傳憑證檔)。

1刪除舊的 repo

第一次設定、沒有舊 repo 的話直接勾完成。
  1. 打開你的 etf-rotation repo → 上方 Settings
  2. 拉到最下面 Danger Zone → Delete this repository
  3. 照畫面指示輸入 repo 名稱確認刪除
刪除前確認第 0 步的資料都準備好了;刪除後舊的金鑰和設定都拿不回來。

2從範本建立新的 repo

  1. 打開範本 → 右上角綠色 Use this template → Create a new repository
  2. Owner 選你自己;Repository name 填 etf-rotation
  3. 選 Private → Create repository
打開範本
建好後告訴分享者,他會收回範本的權限(不影響你的 repo)。

3建立設定用的權杖

  1. 打開權杖頁面;有舊的 etf-rotation 權杖先刪掉
  2. Generate new token:名稱隨意(例「ETF 設定」),到期日選 1 年
  3. Repository access:Only select repositories → 選 etf-rotation
  4. Permissions → Repository permissions,三項都選 Read and write:Contents、Secrets、Actions
  5. Generate token → 複製(只會顯示一次,先貼在記事本)
打開權杖頁面

4初次設定頁(一頁填完)

  1. GitHub:repo 填 你的帳號/etf-rotation,貼第 3 步的權杖 → 檢查
  2. Telegram:貼機器人 Token 與通知 ID
  3. 永豐:API Key、Secret Key、上傳 Sinopac.pfx、憑證密碼、身分證字號
  4. 策略:三組各選一檔 ETF、A=30、B=0;模式先選「只通知」
  5. 寫入:「程式自動更新金鑰」整段貼上(含 BEGIN、END 兩行)→ 確認寫入
打開初次設定頁
約 1 分鐘後 Telegram 會收到「設定已啟用」。金鑰在你的瀏覽器加密後直接存進你自己的 GitHub,不經過其他人。

5更新到最新程式

  1. 你的 repo → 上方 Actions → 左邊 程式自動更新 → 右邊 Run workflow → 綠色 Run workflow
  2. 約 1 分鐘,出現綠色勾勾就完成(沒有新版時也是綠勾)
之後每週日 09:17 會自動檢查更新,有更新時 Telegram 會通知。出現紅色叉叉多半是金鑰沒貼完整,回第 4 步重新貼。

6測試永豐(平日 08:00–18:00)

  1. 初次設定頁最下面按「永豐模擬測試」→ 等 Telegram 回報成功
  2. 再按「正式環境檢查」→ 回報已開通就 OK
也可以在 repo 的 Actions → ETF 輪動通知 → Run workflow,mode 選 simtest / livecheck,account 填 main。

7準時觸發(cron-job.org)

GitHub 自己的排程常延遲好幾小時,換股要準時就需要這步。
  1. 到權杖頁面再建一個:只選 etf-rotation、只開 Actions: Read and write(不要開 Contents)
  2. 登入 cron-job.org。已有兩個排程的話,只要把 Headers 的 Bearer 後面換成新權杖;沒有的話建兩個:
    • URL:https://api.github.com/repos/你的帳號/etf-rotation/actions/workflows/rotation.yml/dispatches
    • Method POST;Headers:Authorization: Bearer 新權杖、Accept: application/vnd.github+json、Content-Type: application/json
    • 午盤:週一~五 13:25,Body {"ref":"main","inputs":{"mode":"noon","account":"all"}}
    • 晚間:每天 20:00,Body 把 noon 改成 evening
    • 時區選 Asia/Taipei
cron-job.org 的「Test run」可能顯示 404,不用理它,以實際排程時間的執行為準。

8日常使用

  • 換 ETF、加個股、改 A/B、改賣出時機、改模式、暫停:都在設定頁(第一次要貼第 3 步的權杖)
  • 先用「只通知」跑一兩次換股,確認通知正常,再改「模擬」或「真單」
  • 每輪賣出後 Telegram 會發「本輪結算」,週日有週報
打開設定頁
把設定頁加到手機主畫面,之後隨時可以查看。
有問題截圖給分享者;金鑰、憑證、身分證字號不要傳給任何人。
