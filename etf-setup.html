ETF 輪動初次設定

依序完成 5 個步驟,資料會從你的瀏覽器直接加密送到你自己的 GitHub,不經過其他伺服器。
金鑰、憑證、身分證字號只輸入在你自己的裝置上,不要交給任何人代填。這個頁面的程式碼是公開的,可以檢查它只連線到 GitHub 與 Telegram。

1連結你的 GitHub

  1. 先用範本建立自己的私人 repo(Use this template → 名稱 etf-rotation → Private)
  2. 到 建立權杖:Repository access 只選你的 etf-rotation; 權限開 Contents、Secrets、Actions 三項,都選 Read and write → Generate → 複製

2Telegram 通知

  1. Telegram 搜尋 @BotFather → 傳 /newbot → 取名字與帳號(結尾要 bot)→ 複製它給的 token
  2. 點 BotFather 給的機器人連結 → 按 Start,再隨便傳一句話給它

3永豐 API(要自動下單才需要)

  1. 永豐金證券網站 → 簽署中心 → 簽所有 API 相關條款
  2. API 管理 → 新增 API Key:勾行情、帳務、交易(有「正式環境」也勾),不要設 IP
  3. 同一頁按 下載憑證,得到 Sinopac.pfx
只在你的瀏覽器裡轉換,加密後直接存進你自己的 GitHub。

4輪動策略

模式先設為「只通知」:程式只發 Telegram 提醒、不會下單。確認沒問題後,再到設定頁面改成模擬或真單。 想長抱不賣的股票,完成後在設定頁面加入。

5寫入 GitHub

填了之後,每週日會自動從範本更新到最新程式(只更新程式,不動你的設定與金鑰)。沒有就留空,之後也能補。
    ✓ 設定完成!約 1 分鐘後 Telegram 會收到「設定已啟用」。
    之後要改 ETF、A/B、模式、暫停,用 設定頁面(這台裝置已記住權杖)。 要準時收到通知或自動下單,請照 SETUP.md 第 11 步設定 cron-job.org。
